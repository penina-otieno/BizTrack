# BizTrack

## Project Overview
BizTrack is an Android application designed to help small businesses such as mini-marts, supermarkets, and kiosks manage their financial records.

## Main Features
- Record sales and expenses
- Manage inventory and product quantities
- Monitor budgets
- Calculate profit and loss
- View financial summaries

## Technologies
- Kotlin
- Android Studio
- Room or SQLite for local data persistence
